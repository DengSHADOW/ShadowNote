# 英文课堂 review

Summary 准确说清研究问题、核心 claim、方法、关键结果；Strengths 选少量有证据的具体贡献；Weaknesses 讨论与 claim 相关的限制、证据缺口，而非无限愿望单。
Presenter questions 应允许解释或讨论，例如一个关键假设为什么合理、某个图如何支持 claim、方法在哪些条件下可能不适用；默认三个，不要求演讲者代作者做新实验。
Overall Assessment 给简短判断和理由，默认不评分。英文少术语堆叠、长句和空泛评价。

SOTA、zero-shot、数值和比较条件逐项回原文核对；区分缺少证据和证伪。外部后续结论必须检查一手来源并与原论文证据区分。
详细定位保留在 evidence.md，不将一页 review 挤成来源清单。每次编译后以真实页数为准；超页删冗余，保留 11pt 和可读间距。修改文件前阅读当前内容，保留用户编辑。

模板正文是明确标注的合成排版验证文字，不是论文分析。正式写作时换为当前 Codex 基于原文写出的内容，不能由脚本套占位句。编译命令禁止 shell escape，缓存保留日志和截图，失败时不覆盖上次合格 PDF。即使编译通过也需视觉查看。

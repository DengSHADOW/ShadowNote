# 智能体间元数据的信任边界

在 MAS 中，数据指内容或回答本身；metadata 则包括状态报告、错误消息、进度更新和 action history。由于 metadata 会影响下一步 agent 的选择和控制流，它应具有明确的来源与信任语义，而不能仅因来自另一 agent 就被视为可信。（PDF p. 4，§2.2）

> **英文原文：** “metadata can influence control-flow decisions even when primary outputs are properly secured.”（PDF p. 4，§2.2）

本文显示，恶意内容可伪装成合理错误信息，经前线 agent 传递至 orchestrator。若系统未区分“由不可信外部内容派生的报告”和“可信内部控制信息”，就可能形成 [[多智能体系统控制流劫持|多智能体系统控制流劫持]] 的路径。（PDF p. 5，§4）

> **英文原文：** “The attack exploits inter-agent trust and leverages adaptive error-handling behavior.”（PDF p. 5，§4）

作者认为现有 MAS 缺少类似传统操作系统或浏览器的信任模型与输入语义；潜在缓解方向包括 source tagging、structured queries、tool-call validation 与 information-flow controls，但论文没有测量这些方法的实际防御效果。（PDF p. 9–10，§7.2–8；PDF p. 17，附录 A.3）

> **英文原文：** “they do not have a trust model, nor any semantics of inputs, actions, etc.”（PDF p. 10，§8）

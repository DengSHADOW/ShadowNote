# 分类体系条件化消费组件

分类体系条件化消费组件，是一种搜索、运行时或选择组件，它接收触发的代码和轨迹证据作为结构化反馈。

在论文中，AdaEvolve 使用这种反馈进行架构变异；Claude Code 和 SWE-agent 的 harness 将其用于运行时检查点；AdaMAST-Judge 将其用于轨迹选择。当证据内容保持不变时，使用分类体系并不意味着类别化格式一定优于自然语言表述（PDF pp. 1、37）。

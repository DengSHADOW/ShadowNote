# 开放集目标检测（open-set object detection）

开放集目标检测使用语言指定需要定位的概念，使检测器能够处理固定训练类别之外的输入。来源论文把 open-set object detection、open-world object detection 和 open-vocabulary object detection 视为同一任务，并统一采用 open-set object detection 这一名称。（PDF p. 2，§1）

> **英文原文：** “We view the terms open-set object detection, open-world object detection, and open-vocabulary object detection the same task in this paper.”

在 [[Grounding-DINO]] 中，语言不是仅用于最终类别匹配，而是在 feature enhancer、query 初始化和 decoder 中参与视觉特征处理。这使开放集检测成为一种文本条件化的定位流程。（PDF pp. 2–7，Figures 2–3）

> **英文对应表述（非逐字原文）：** In Grounding DINO, language conditions feature enhancement, query initialization, and decoding rather than serving only as a final classifier.

## Zero-shot 的限定

该论文将 zero-shot 定义为不使用目标数据集的训练 split；这一定义允许训练数据包含与目标 benchmark 相同或近似的类别。（PDF p. 2，脚注 1）

> **英文原文：** “‘Zero-shot’ refers to scenarios where the training split of the test dataset is not utilized in the training process.”

因此，评估开放集检测时需要分别检查数据集 split、类别重叠、图像重叠和标注重叠。[[2303.05499v5 (1)|来源论文]]中的 COCO、REC 和 LVIS oracle 配置分别暴露了类别覆盖、潜在图像泄漏和 pseudo-labeler 使用目标数据的问题。

> **英文对应表述（非逐字原文）：** Open-set evaluation should separately track split usage, category overlap, image overlap, and annotation overlap; the paper reports limitations involving each of these dimensions.

## 经验边界

LVIS rare-category 弱点、ODinW 的领域间波动以及加入 RefC 后的外域性能下降表明，开放集检测仍然显著依赖预训练概念覆盖和数据分布。（PDF pp. 10–13、29–33，Tables 3、4、6、12–18）

> **英文对应表述（非逐字原文）：** Rare-category weakness, large cross-domain variance, and negative transfer after adding RefC show that open-set detection remains dependent on concept coverage and training distribution.

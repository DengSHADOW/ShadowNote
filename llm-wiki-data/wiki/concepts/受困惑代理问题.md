# 受困惑代理问题

受困惑代理问题（confused deputy）描述一个本应受信的组件把不可信输入误作可信请求，并以其自身权限执行或推动该请求。在本文的 MAS 场景中，接触恶意内容的 sub-agent 把攻击指令转述为内部状态或错误报告，使 orchestrator 将其当作可信 agent 输出处理。（PDF p. 2，§1；PDF p. 5，§4）

> **英文原文：** “adversarial content turns sub-agents into ‘confused deputies.’”（PDF p. 2，§1）

该问题的关键不是某个 agent 是否原本恶意，而是系统是否把 agent 输出的来源、权限和数据性质一概视为可信。前线 agent 的报告可因此跨越 [[智能体间元数据的信任边界|智能体间元数据的信任边界]]，影响具有更多工具或执行权限的组件。（PDF p. 4–5，§2–4）

> **英文原文：** “These systems delegate tasks to individual sub-agents and trust that they correctly report the status of their tasks.”（PDF p. 2，§1）

在本文框架中，[[请求洗白|请求洗白]] 是受困惑代理问题的具体表现：攻击者请求经由 agent 输出重新呈现，改变其被 orchestrator 接收和解释的方式。（PDF p. 5，§4）

> **英文原文：** “laundering the request through another agent’s metadata significantly changes its presentation.”（PDF p. 5，§4）

# 可提示 3D 目标检测

可提示 3D 目标检测通过 text、2D point、2D box 或 visual exemplar 指定目标，并输出目标的 3D box。它将[[可提示分割]]中的交互式目标指定方式扩展到 metric 3D localization，但预测对象从 2D mask 变为 center、dimensions 和 orientation。（PDF pp. 4–7，§2.2–2.3）

> **英文对应表述（非逐字原文）：** Promptable 3D detection uses language or geometric interaction to select objects whose metric 3D boxes must then be recovered.

## WildDet3D 的实现

[[WildDet3D]]使用 CLIP-style tokenizer 与 causal text Transformer 编码 text；使用 coordinates、ROI/grid-sampled image features 和 sinusoidal position encoding 编码 point 与 box。所有 prompt tokens 被拼接为 cross-attention memory。（PDF p. 6，§2.2）

> **英文对应表述（非逐字原文）：** Text and geometric prompts are encoded differently but enter a shared attention-based conditioning interface.

text prompt 选择类别的全部实例；point 与 box 通常指定单个实例；exemplar box 则通过 special token 与 multi-target matching 查找视觉上相似的同类对象。（PDF p. 6，§2.2）

> **英文对应表述（非逐字原文）：** Prompt semantics determine whether supervision targets one localized object or multiple category-consistent instances.

## 方法边界

box-prompt oracle results 隔离了 3D regression，但依赖 ground-truth 2D localization；text-prompt results 同时包含 2D detection 与 3D lifting 的误差。因此不同 prompt mode 的 AP 不能被视为完全等价的系统能力。（PDF pp. 13–16，§4.1–4.3）

> **英文对应表述（非逐字原文）：** Oracle boxes remove much of the 2D localization burden, whereas text prompting evaluates the full detection-and-lifting pipeline.

# 可提示分割（promptable segmentation）

可提示分割要求模型在收到任意分割提示后，返回至少一个合理的有效 mask。提示可以是前景点、背景点、框、已有 mask 或文本；当提示存在歧义时，任务允许多个不同但合理的答案。（PDF pp. 2–3，§2）

> **英文对应表述（非逐字原文）：** Promptable segmentation asks a model to return at least one valid mask for a segmentation prompt, while allowing multiple valid outputs when the prompt is ambiguous.

在 [[2304.02643v1 (1)|Segment Anything]] 中，该任务同时承担预训练目标和零样本迁移接口。[[SAM]] 不必针对每个下游任务重新训练；系统可以把检测框、文本 embedding 或交互输入转换成提示，以组合方式完成新任务。（PDF pp. 2–3、7–10，§2 与§5）

> **英文对应表述（非逐字原文）：** The promptable task serves both as a pretraining objective and as an interface through which external components can adapt SAM to downstream tasks.

这一任务定义的关键不是给定提示必须对应唯一 ground truth，而是输出应满足提示并构成视觉上有效的对象。该性质直接引出[[歧义感知多掩码预测]]，也使单一 IoU ground truth 难以完整评价输出质量。（PDF pp. 2–4，§2–3；PDF pp. 23–24，§E）

> **英文对应表述（非逐字原文）：** Validity is conditioned on the prompt rather than on a uniquely determined ground-truth mask, motivating multiple predictions and human evaluation beyond dataset IoU.

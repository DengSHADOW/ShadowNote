# WildDet3D: Scaling Promptable 3D Detection in the Wild

## 来源信息

- 作者：Weikai Huang、Jieyu Zhang、Sijun Li、Taoyang Jia、Jiafei Duan、Yunqian Cheng、Jaemin Cho、Matthew Wallingford、Rustin Soraki、Chris Dongjoo Kim、Shuo Liu、Donovan Clay、Taira Anderson、Winson Han、Ali Farhadi、Bharath Hariharan、Zhongzheng Ren、Ranjay Krishna

- 演示：https://huggingface.co/spaces/allenai/WildDet3D

## 核心贡献

论文提出 [[WildDet3D]]：一个接受 text、2D point、2D box 和 exemplar prompt 的开放词汇单目 3D 检测器。模型预测目标的 metric center、physical dimensions、orientation 与 confidence，并可在推理时接收 partial 或 full depth；缺少 intrinsics 或 depth 时则使用内部估计模块。（PDF pp. 4–7，§2，Figures 2–3）

> **英文对应表述（非逐字原文）：** WildDet3D unifies text, point, box, and exemplar prompts for monocular 3D box prediction, while treating camera intrinsics and depth as optional inputs.

论文同时构建 [[WildDet3D-Data]]，报告规模为 `1,003,886 images`、`3,728,078 annotations` 和 `13,499 categories`。其中训练集包括 `102,979` 张人工标注图像和 `896,004` 张经 VLM 筛选的图像，因此不能将全部约一百万张图像概括为逐项人工验证。（PDF pp. 9–13，§3，Tables 1–2）

> **英文对应表述（非逐字原文）：** The dataset combines roughly 103K human-annotated training images with about 896K VLM-filtered training images, rather than one million uniformly human-verified images.

## 模型设计

### 可提示检测接口

[[可提示-3D-目标检测]]将四种 prompt 映射到统一 token 序列：text prompt 检索同类实例；point 与 box prompt 指定单个目标；exemplar prompt 使用视觉示例查找同类目标。编码后的 prompt tokens 在 encoder 和 decoder 中作为 cross-attention memory。（PDF p. 6，§2.2）

> **英文对应表述（非逐字原文）：** Text selects category instances, geometric prompts select a localized object, and exemplar boxes retrieve visually similar instances through a shared prompt representation.

### 可选深度的双编码器融合

模型分别使用基于 SAM 3 权重的 ViT-H + SimpleFPN 提取语义特征，以及基于 LingBot-Depth 权重的 DINOv2 ViT-L/14 提取 RGBD geometry latents。[[可选深度的双编码器融合]]以 zero-initialized residual branch 合并两者：（PDF pp. 5–6，§2.1）

$$
V' = V+\operatorname{Conv}_{1\times1}(\operatorname{LN}(Z_d^\uparrow))
$$

> **英文对应表述（非逐字原文）：** A zero-initialized residual projection adds normalized, upsampled depth latents to semantic image features without initially perturbing the pretrained visual stream.

RGBD encoder 的训练输入按 `70%` zero depth、`20%` patch-masked depth 和 `10%` full depth 采样，使同一架构能够处理无深度、部分深度与完整深度输入。（PDF p. 5，§2.1）

> **英文对应表述（非逐字原文）：** Stochastic depth conditioning trains the geometry branch across monocular, partially observed, and fully observed depth regimes.

### 3D head 与旋转参数化

每个 decoder layer 均输出 3D prediction 并接受等权监督。camera ray 由 intrinsics 生成，再以 8th-order real spherical harmonics 编码；随后，camera-ray features 与 depth latents 依次通过 cross-attention 注入 query。（PDF pp. 6–7，§2.3）

> **英文对应表述（非逐字原文）：** Every decoder layer is supervised, and its queries sequentially attend to spherical-harmonic camera rays and learned depth latents.

3D box 使用 12 维参数表示：

$$
p_{3d}=(\Delta c_x,\Delta c_y,\hat d,\hat w,\hat h,\hat l,r_1,\ldots,r_6)
$$

其中 rotation 由旋转矩阵前两行的 6D representation 表示，并通过 Gram–Schmidt 恢复完整矩阵。[[无歧义-3D-box-rotation-normalization]]进一步规定 `w ≤ l`，并将 yaw 折叠到 `[0,\pi)`。（PDF p. 7，§2.3）

> **英文对应表述（非逐字原文）：** Dimension ordering and yaw folding collapse equivalent box parameterizations into a single regression target.

3D confidence 的监督与推理重排序分别为：

$$
q^*=\beta q_{\text{depth}}+(1-\beta)\operatorname{IoU}_{3D},\qquad \beta=0.7
$$

$$
s=s_{2D}+\alpha s_{3D},\qquad \alpha=0.5
$$

该分支以 depth quality 为主要成分，同时保留 2D objectness 的主导地位。（PDF p. 7，§2.3，Eqs. 6–7）

> **英文对应表述（非逐字原文）：** The quality target emphasizes depth accuracy, while inference adds a smaller geometry-aware score to the dominant 2D objectness score.

## 训练信号

每个 ground-truth object 通过 one-to-many matching 与 top-4 predictions 配对。总损失由 3D regression、3D confidence、geometry estimation 和辅助 2D detection 构成；geometry branch 还接受 metric depth、SILog、point-map alignment、confidence mask 与 camera-ray losses。（PDF pp. 8、28–29，§2.4，Appendix A）

> **英文对应表述（非逐字原文）：** Top-four one-to-many matching increases supervision density, while auxiliary 2D and geometry objectives jointly anchor image localization and metric reasoning.

在 Omni3D oracle ablation 中，移除辅助 2D head 使 AP 从 `30.2` 降至 `11.1`，而移除 3D confidence head 降至 `29.4`。该结果支持 2D localization 是 3D regression 的关键锚点，但论文未报告多随机种子方差。（PDF p. 17，§4.6，Table 7）

> **英文对应表述（非逐字原文）：** The reported single-run ablation shows a 19.1 AP loss without the 2D head, compared with a 0.8 AP loss without geometry-aware confidence.

移除 O2M matching、geometry loss、deep supervision 和 ignore-aware suppression 分别降低 `2.5`、`1.7`、`0.3` 和 `0.2 AP`。这些是同一配置内的直接消融，但没有分析组件之间的交互作用。（PDF pp. 17–18，§4.6，Table 8）

> **英文对应表述（非逐字原文）：** O2M matching and geometry supervision have the largest individual ablation effects among the tested training objectives.

## 数据构建流程

[[多模型候选-人工-VLM-混合-3D-标注]]从 COCO、LVIS、Objects365 和 V3Det 的 2D annotations 出发，利用 MoGe-2、PerspectiveFields 与 WildCamera 构建 metric point cloud，再由 3D-MOOD、DetAny3D、SAM-3D、RANSAC-PCA 和 LabelAny3D 生成候选 3D boxes。（PDF pp. 9–10，§3.1，Figure 4）

> **英文对应表述（非逐字原文）：** Five complementary learned and geometric lifting methods propose candidate boxes over depth-derived point clouds built from existing 2D annotations.

候选随后经过几何规则、depicted-object filter、composite-image filter，以及由 GPT-4.1-mini 估计的类别尺寸和形状范围过滤。人工分支由 Prolific 标注者选择并评级；自动分支由 fine-tuned Molmo2 按六项准则评分，仅保留总分大于 `10` 的最高分候选。（PDF pp. 10–12，§3.2–3.3）

> **英文对应表述（非逐字原文）：** Rule-based checks, language-model size priors, human selection, and Molmo2 scoring jointly determine which candidates become valid annotations.

人工验证显示，各候选生成器的 rejection rate 从 RANSAC-PCA 的 `12.5%` 到 DetAny3D 的 `42.9%`。VLM score bins 与 rejection rate 单调对应，但 AUC 仅为 `0.66`，且 score `10` 的人工 rejection rate 仍为 `16.7%`，因此自动评分不能被解释为人工验证的等价替代。（PDF pp. 12–13，§3.5，Table 2）

> **英文对应表述（非逐字原文）：** Aggregate score bins are monotonic, but candidate-level discrimination remains moderate and high-scoring proposals still contain substantial human-rejected cases.

## 非穷举标注与评估

[[非穷举-3D-标注下的-ignore-region-suppression]]处理具有有效 2D box、但缺少可靠 3D ground truth 的对象。训练时，若 prediction 与 ignore box 的 2D IoU 超过 `0.5`，其负分类损失被抑制；评估时，与 ignore object 匹配的 prediction 视为 neutral。（PDF pp. 8–9，§2.4）

> **英文对应表述（非逐字原文）：** Predictions overlapping ignored 2D regions are neither trained as ordinary negatives nor counted as false positives during evaluation.

WildDet3D-Bench 与 Stereo4D 使用基于对象 half-diagonal 的 center-distance matching；Omni3D 使用 10 个 3D IoU thresholds。Argoverse 2 与 ScanNet 使用 Open Detection Score：（PDF pp. 13–14、29–30，§4.1，Appendix C）

$$
\operatorname{ODS}=
\frac{3\operatorname{AP}+(1-\operatorname{mATE})+(1-\operatorname{mAOE})+(1-\operatorname{mASE})}{6}
$$

> **英文对应表述（非逐字原文）：** ODS assigns half of its weight to AP and distributes the remainder across normalized translation, orientation, and scale accuracy.

## 主要实验结论

在相同 Omni3D 训练数据下，WildDet3D 的 text-prompt AP 为 `6.8`，高于 3D-MOOD 的 `2.3`；box-prompt AP 为 `8.4`，高于 OVMono3D-LIFT 的 `7.7`。加入 `Others + WildDet3D-Data` 后分别达到 `22.6` 和 `24.8 AP`，但该实验没有单独隔离 WildDet3D-Data 与 Others 的贡献。（PDF pp. 14–15，§4.2，Table 3）

> **英文对应表述（非逐字原文）：** Same-data comparisons favor WildDet3D, whereas the larger training mixture does not identify the separate effects of WildDet3D-Data and the supplementary datasets.

在 Omni3D 上，text 与 box prompt 分别取得 `34.2` 和 `36.4 AP3D`；加入测试时 depth 后分别为 `41.6` 和 `45.8`。这些结果覆盖 ground-truth 或 sparse depth 条件，不能直接推广为任意现实传感器的统一增益。（PDF pp. 15–16、18，§4.3、§4.6，Table 4）

> **英文对应表述（非逐字原文）：** Depth-conditioned gains are substantial on Omni3D, but their deployment meaning depends on the source, density, and quality of the supplied depth.

仅以 Omni3D 训练时，WildDet3D 在 Argoverse 2 与 ScanNet 的 zero-shot evaluation 中取得 `40.3` 和 `48.9 ODS`。论文未逐类别披露与训练数据的词汇或视觉实例重叠，因而 zero-shot 应理解为跨数据集设置，而非所有类别均为 train-unseen。（PDF pp. 15–16，§4.4，Table 5）

> **英文对应表述（非逐字原文）：** The protocol is dataset-level zero-shot transfer; it does not establish that every evaluated category or visual concept was absent from training.

在 383 张图像、78 个类别的 Stereo4D 测试中，box-prompt WildDet3D 从无 depth 的 `7.5 AP` 提升到真实 stereo depth 下的 `27.7 AP`。这一结果更接近实际 depth 输入，但样本量较小，且只覆盖 box-prompt setting。（PDF pp. 16–17，§4.5，Table 6）

> **英文对应表述（非逐字原文）：** Real stereo depth provides a large gain in a small zero-shot box-prompt evaluation, offering deployment-relevant but limited evidence.

## 解释边界与局限

论文按 evaluation frequency 定义 rare、common 和 frequent，因此 rare-category improvement 不等同于 novel-category generalization。正文又称大多数 validation categories 在训练集中至少出现一次，进一步限制了将 rare 结果解释为 train-unseen 泛化的合理性。（PDF pp. 12、14–15，§3.4、§4.1–4.2）

> **英文对应表述（非逐字原文）：** Frequency-defined rarity and training-set novelty are distinct properties and should not be treated as interchangeable evidence.

正文的 `826/881 = 99.9%` 在算术上不成立，实际约为 `93.8%`；同一论文还出现 `785` 个 val categories、`810` 个 frequency-group categories 和 `881` 个 validation categories。各数字对应的去重、过滤或评估集合没有得到充分说明。（PDF pp. 12、14，§3.4、§4.1，Table 1）

> **英文对应表述（非逐字原文）：** The reported category totals and percentage cannot be reconciled without additional definitions for split construction and evaluation filtering.

Tables 7–8 的 full model 为 `30.2 AP3D`，而 Table 4 中 Omni3D box-prompt WildDet3D 为 `36.4 AP3D`。论文说明消融均为 Omni3D-only oracle setting，但未充分解释两者的训练或评估配置差异。（PDF pp. 16–17，Tables 4、7–8）

> **英文对应表述（非逐字原文）：** The main oracle result and the ablation reference use different AP values despite apparently similar high-level settings.

论文将 12 epochs 与 baseline 的 80–120 epochs 比较，但 WildDet3D 使用 SAM 3 与 LingBot-Depth 的强预训练，且不同数据集的 epoch 并不对应相同样本数或总计算量。因此该比较说明训练日程较短，不足以证明 compute-normalized efficiency。（PDF pp. 14–15、29，§4.1、§4.3，Appendix B）

> **英文对应表述（非逐字原文）：** Fewer epochs do not by themselves establish lower total compute when initialization, dataset size, and per-epoch workload differ.

作者明确指出 camera calibration、single-image scale ambiguity、rotation estimation、dual-backbone compute 和 long-tail variation 仍是限制，并将 iPhone、AR、robotics 与 VLM demos 定位为 research prototypes，而非 production-ready 或 safety-critical systems。（PDF p. 22，§7）

> **英文对应表述（非逐字原文）：** The demonstrations establish integration feasibility, not bounded reliability, real-time efficiency, or readiness for safety-critical deployment.

## 与现有知识的关系

WildDet3D 将 [[可提示分割]]的交互范式扩展到 metric 3D boxes，但其任务输出、geometry supervision 与 evaluation protocol 均不同于 [[SAM]]。论文采用 SAM 3 的 encoder 与 prompt design，也不能据此将 SAM 3 与现有 SAM 实体视为同一模型版本。

> **英文对应表述（非逐字原文）：** WildDet3D borrows promptable design ideas but changes the task from 2D mask prediction to metric 3D box estimation.

[[Grounding-DINO]]与[[开放集目标检测]]提供 text-conditioned 2D localization 的相关背景；WildDet3D 的新增问题是从图像线索恢复 metric scale、3D position 和 orientation。本文未将 Grounding DINO 用作核心 backbone。

> **英文对应表述（非逐字原文）：** Open-vocabulary 2D grounding is related prior work, while WildDet3D concentrates on geometry-aware lifting and 3D regression.

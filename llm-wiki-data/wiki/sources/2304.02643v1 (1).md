# Segment Anything

## 来源概况

论文提出 Segment Anything（SA）项目，由可提示分割任务、[[SAM|Segment Anything Model（SAM）]] 和 [[SA-1B|Segment Anything 1B（SA-1B）]] 三部分组成。其目标是把分割任务转化为接受点、框、mask 或初步文本等提示的通用接口，并通过 prompt engineering 或外部组件组合实现零样本迁移。（PDF pp. 1–3，摘要与§1–2）

> **英文对应表述（非逐字原文）：** Segment Anything combines a promptable segmentation task, the Segment Anything Model, and the SA-1B dataset, treating prompts as a general interface for transferring the model to downstream segmentation tasks.

## 模型与歧义处理

SAM 使用 MAE-pretrained ViT-H/16 image encoder、prompt encoder 和轻量 mask decoder。decoder 通过双向 cross-attention 融合提示与图像表示；预计算 image embedding 后，prompt encoder 与 mask decoder 可在浏览器 CPU 上约 `50 ms` 内响应，但该数字不包含重量级 image encoder 的完整端到端成本。（PDF pp. 3–5，§3；PDF pp. 16–17，§A）

> **英文对应表述（非逐字原文）：** SAM uses a MAE-pretrained ViT-H/16 image encoder, a prompt encoder, and a lightweight two-way cross-attention mask decoder. The reported browser latency applies after the image embedding has been computed.

单个提示可能同时合理地指向 whole、part 或 subpart。SAM 因而默认生成 3 个候选 mask 和对应的 predicted IoU，并只从训练损失最低的候选反向传播。该经验设计覆盖常见嵌套歧义，但不是对所有非嵌套、多对象或语义歧义的完备建模。（PDF p. 4，§3；PDF p. 17，§A）

> **英文对应表述（非逐字原文）：** For an ambiguous prompt, SAM predicts three candidate masks and trains with a minimum-loss rule so that distinct outputs can represent common whole, part, and subpart interpretations.

### 默认架构与训练配置

| 项目 | 精确设置 |
|---|---|
| Image encoder | MAE pre-trained ViT-H/16 |
| Attention | `14×14` windowed attention；4 个 equally-spaced global attention blocks |
| Input resolution | `1024×1024` |
| Image embedding | `256×64×64` |
| Prompt embedding dimension | `256` |
| Decoder layers | `2` |
| Transformer MLP internal dimension | `2048` |
| Cross-attention Q/K/V dimension | `128` |
| Attention heads | `8` |
| Decoder dropout | `0.1` |
| Upsampling | 两个 `2×2, stride 2` transposed convolutions；输出 channels 为 `64`、`32` |
| Ambiguous single prompt | 返回 `3` 个 masks |
| Multiple prompts | 仅返回专用第 `4` 个 output token 对应的 mask |
| Mask loss | focal loss : dice loss = `20:1` |
| IoU head loss | mean-square-error；mask loss scaling factor `1.0` |
| Interactive iterations | 1 个初始提示 + 8 个迭代点 + 2 个无新增点 refinement = `11` |
| Optimizer | AdamW，`β1=0.9, β2=0.999` |
| Warmup | `250 iterations` |
| Initial learning rate | `8e−4` |
| Training length | `90k iterations`，约 `2 SA-1B epochs` |
| LR decay | 在 `60k` 与 `86666` iterations 各下降 `10×` |
| Batch size | `256 images` |
| Weight decay | `0.1` |
| Drop path | `0.4` |
| Layer-wise LR decay | `0.8` |
| Distributed training | `256 GPUs` |

（PDF pp. 16–17，§A）

## 数据引擎与 SA-1B

[[分割数据引擎]]分为辅助人工、半自动和全自动三个阶段。前两阶段分别产生约 120k 图像、4.3M masks，以及新增约 180k 图像、5.9M masks；全自动阶段扩展至 11M 图像和约 1.1B masks。公开 SA-1B 只包含 SAM 自动推断的 masks，不包含模型辅助人工标注。（PDF pp. 5–7，§4；PDF pp. 27–29，Dataset Card 与 Data Annotation Card）

> **英文对应表述（非逐字原文）：** The data engine progressed from model-assisted manual annotation to semi-automatic annotation and finally fully automatic mask generation. The released SA-1B masks are automatically generated rather than the manual masks produced during earlier stages.

自动生成流程结合全图点网格、重叠 crops、两阶段 NMS、predicted-IoU 筛选、稳定性筛选及小连通分量后处理。抽样人工修订显示，94% 的自动 masks 与专业修订结果的 IoU 超过 90%，但这一抽样结果不能排除系统性遗漏或长尾错误。（PDF pp. 6–7，§4；PDF p. 18，§B）

> **英文对应表述（非逐字原文）：** Automatic mask generation uses dense point grids, multi-scale crops, non-maximum suppression, predicted-IoU and stability filters, and component cleanup. In a sampled comparison with professional corrections, 94% of masks exceeded 90% IoU.

### SA-1B 自动掩码生成配置

| 阶段 | 精确设置 |
|---|---|
| Full-image sampling | `32×32` regular point grid |
| Zoomed-in crops | 20 个 crops：`2×2` 与 `4×4` partially overlapping windows |
| Crop point grids | 分别为 `16×16` 与 `8×8` |
| Crop-boundary rule | 移除接触 crop 内边界的 masks |
| NMS | 先 crop 内、再跨 crops；两阶段 threshold 均为 `0.7` |
| Within-crop ranking | predicted IoU |
| Across-crop ranking | 从最 zoomed-in 到最不 zoomed-in |
| Predicted IoU filter | threshold `88.0` |
| Stability filter | `-1` 与 `+1` 阈值 masks 的 IoU `≥95.0` |
| Full-image filter | 移除覆盖图像 `≥95%` 的 masks |
| Small components | 移除面积 `<100 pixels` 的 connected components |
| Small holes | 填充面积 `<100 pixels` 的 holes |
| Generation-model training | `177656 iterations` |
| Sampled points during training | 每个 mask `4` 点 |
| Generation-model decoder | `3` layers |

（PDF p. 18，§B）

## 零样本评估

评估覆盖单点分割、edge detection、object proposals、instance segmentation 和 text-to-mask。单点实验中，SAM 在 23 个数据集中的 16 个默认 mIoU 测试上优于 RITM；若以 ground truth 从 3 个候选中进行 oracle 选择，则在全部 23 个数据集上优于 RITM。oracle 结果说明候选生成能力强于默认排序所呈现的性能，也暴露了 predicted-IoU ranking 的改进空间。（PDF pp. 7–8，§5.1；PDF pp. 19–21，§D.1）

> **英文对应表述（非逐字原文）：** SAM outperformed RITM on 16 of 23 datasets with its default one-point output, while an oracle selection among three candidates outperformed RITM on all 23 datasets.

在 BSDS500 zero-shot edge detection 上，SAM 的 ODS、OIS、AP 和 R50 分别为 `.768`、`.786`、`.794` 和 `.928`。模型预测的部分额外边缘可能在视觉上合理，却因不符合数据集的标注习惯而降低 precision。（PDF pp. 8–9，§5.2；PDF p. 21，§D.2）

> **英文对应表述（非逐字原文）：** On BSDS500, SAM obtains strong zero-shot edge recall, but it often predicts more edges than the dataset annotations contain, which lowers precision under the benchmark protocol.

在 instance segmentation 中，SAM 的 COCO/LVIS AP 为 `46.5/44.7`，低于 ViTDet-H 的 `51.0/46.6`；人工质量均值却为 SAM `8.1±0.07`、ViTDet-H `7.9±0.08`。论文把这种排序差异与数据集标注偏好、边界风格及 [[modal-amodal-标注错位]]联系起来。（PDF pp. 9–10，§5.4；PDF pp. 22–26，§D.4 与§E）

> **英文对应表述（非逐字原文）：** ViTDet-H scores higher under COCO and LVIS AP, whereas human raters assign SAM masks a slightly higher average quality score, suggesting that benchmark agreement and perceived mask quality are not identical.

## 人工质量研究

[[ground-truth-independent-mask-quality-evaluation|不依赖 ground truth 的掩码质量评估]]要求专业标注员从有效对象、边界质量和提示一致性三个方面给 mask 打 1–10 分。七个单点数据集各抽取 1000 个输入、形成 4000 个评分任务；LVIS v1 实例分割抽取 1000 个输入、形成 3000 个任务。（PDF pp. 23–25，§E）

> **英文对应表述（非逐字原文）：** Human raters scored masks from one to ten according to whether they represented a valid object, had clean boundaries, and matched the point or box prompt.

Table 8 报告 SAM 相对 RITM、single-output SAM 和 ViTDet-H 的差异均达到统计显著，99% bootstrap confidence intervals 均不跨零。不过正式实验中每个任务只有一名标注员；五人重复评分只用于前期试验，其评分标准差均值为 `0.83`。（PDF pp. 24–26，Figure 18 与Table 8）

> **英文对应表述（非逐字原文）：** The reported pairwise differences are statistically significant, but the production study assigns only one rater to each mask after a smaller five-rater pilot.

Figure 18 的 OVIS 抽取值与 Table 8 的方向不一致：抽取结果似乎显示 single-output SAM 高于 SAM，而 Table 8 给出 SAM 相对 single-output SAM 的正差值 `99% CI (0.27, 0.63)`。在直接核对 PDF 图像前，不应把抽取值作为已解决证据。（PDF pp. 25–26，Figure 18 与Table 8）

> **英文对应表述（非逐字原文）：** The extracted OVIS values from Figure 18 conflict with the positive SAM-minus-single-output confidence interval reported in Table 8 and require direct visual verification.

## 公平性、地域与发布责任

人物整体分割未显示明显的 perceived gender presentation 或 perceived skin tone 差异，但这不能推广为所有人物相关任务均公平。服装单点分割中，feminine 与 masculine 的 mIoU 分别为 `76.3±1.1` 和 `81.0±1.2`；使用 3 点后分别为 `90.7±0.5` 和 `92.3±0.4`。（PDF pp. 11–12，§6；PDF p. 19，Table 6）

> **英文对应表述（非逐字原文）：** The person-segmentation study finds small group differences, while the clothing task shows a larger perceived-gender-presentation gap with one point that narrows with three points.

SA-1B 的 Europe 和 Asia & Oceania 占比分别为 `49.8%` 和 `36.2%`，low income countries 仅占 `0.9%`。地点由受限 caption 近似推断，存在缺失、选择偏差和 “Georgia” 一类实体歧义，因此这些数字不应被解释为精确地理标注。（PDF pp. 6–7，Table 1；PDF p. 18，§C）

> **英文对应表述（非逐字原文）：** SA-1B has broader coverage than some comparison datasets in selected regions, but its inferred geographic distribution remains uneven and depends on ambiguous, incomplete caption-derived locations.

[[隐私保护型数据发布]]包括把图像短边缩放至 `1500 pixels`、使用 RetinaFace 检测并模糊人脸、模糊车牌，以及不发布未处理原图。论文没有报告人脸或车牌模糊的漏检率，也没有提供独立重识别评估。（PDF pp. 27–29，Dataset Card）

> **英文对应表述（非逐字原文）：** Released images are resized and have detected faces and license plates blurred, while original unblurred images are not released; the paper does not report independent re-identification testing or blur miss rates.

## 局限与使用边界

SAM 主要面向研究和 prompt-based segmentation。已知局限包括遗漏细结构、生成小型断开分量、text-to-mask 鲁棒性不足，以及完整端到端速度仍受 ViT-H image encoder 限制。下游系统仍需针对具体任务重新评估公平性、错误模式与隐私风险。（PDF pp. 12、30，§7 与Table 9）

> **英文对应表述（非逐字原文）：** SAM is primarily a research model for prompt-based segmentation and may miss fine structures or hallucinate small disconnected components; downstream users remain responsible for task-specific evaluation.

最终训练使用 `256 A100 GPUs`、持续 `68 hours`，估算消耗 `6963 kWh` 并产生 `2.8 metric tons` CO₂，约等于美国普通汽油乘用车行驶 `∼7k miles`。披露范围未明确涵盖数据引擎迭代、消融或失败训练。（PDF p. 30，Table 9）

> **英文对应表述（非逐字原文）：** The model card reports 256 A100 GPUs for 68 hours, approximately 6963 kWh, and an estimated 2.8 metric tons of carbon dioxide for the final training run.
